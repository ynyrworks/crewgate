## Plans

### drift-question - 0.23：工作偏離計畫時問使用者

- Goal: 工作偏離已定版的計畫時，用同一題四選一問使用者，答案記下來；只在程式能確定的地方問，而且不會變吵。
- Completion: 6/7 (86%)
- Clarified:
  - Q: 手改計畫檔怎麼辦？ A: 內容雜湊對不上時，派工或驗收前一律先問四選一，回答後才更新雜湊。
  - Q: 回答後發生什麼？ A: 加進計畫：新增步驟，回答就算核准。修改目標：更新目標，不必重新定版。開新計畫：建立新草稿，定版才能開工。放棄或延後：放棄寫進不做什麼，延後進待辦。每次都記事件和計畫檔一行。
  - Q: 無關的小修怎麼辦？ A: crew task create --outside-plan "原因"，不用先回覆，但原因會記錄並顯示；試用時看它被用幾次，防濫用。
  - Q: 一輪和範圍外檔案怎麼算？ A: 同一類觸發點，在使用者兩則訊息之間只問一次。accept 比對分支改動和 --allow、--deny；沒設範圍不檢查；沒掛計畫的任務問擴大範圍或退回。
  - Q: 什麼算太吵？ A: 不訂數字。crew plan drift-stats 印出每計畫提問次數、四種答案比例、--outside-plan 次數；某觸發點幾乎都答加進計畫就收緊再發佈 0.24。
